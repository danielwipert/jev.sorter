# Working rules for this repo

## Git: one working branch + main
- `main` is the core default branch. Keep the repo to `main` plus the branch we're working on in the current session. No long-lived side branches.
- Work on the session's branch, commit as we go.
- **At the end of every session: push, open a PR into `main`, and merge it.** Do this without asking; Dan has approved it as standard practice.
- Take repo housekeeping actions like this directly rather than handing Dan instructions, when the tools allow it.

## Session habits
- Rewrite `handoff.md` at the end of every session (what we did + what's next). It does not stack; keep it small.
- The spec lives in `planning/`.
- Dan codes mostly in Python and likes things step by step, explained simply.
